# Калькулятор КЗИ и УЗИ

Самопроверка по двум методикам ФСТЭК России в интерфейсе CheckU (УЦСБ). Режим выбирается переключателем вверху страницы.

## КЗИ - показатель защищённости

- Методика оценки показателя состояния технической защиты информации (утв. ФСТЭК России 11.11.2025), Требования, утверждённые приказом ФСТЭК России от 11.04.2025 № 117.
- 16 показателей в четырёх группах, формулировки дословно по таблице 1 Методики, критерии по условиям показателей и приложению № 1.
- Неприменимость показателей по сноскам Методики, условия обнуления групп (примечание к таблице 1 и п. 35).
- Отчёт во ФСТЭК России по шаблону KZI_report.doc и текущий отчёт с перечнем подтверждающих документов.

## УЗИ - уровень зрелости

- Методика оценки уровня зрелости деятельности в области технической защиты информации (утв. ФСТЭК России 07.08.2026).
- 21 направление, по каждому 8 видов требований таблицы 2 с дословными вариантами ответа.
- Уровень направления по таблице 3, УЗИ как среднее уровней направлений, уровень зрелости по таблице 1, целевой уровень по п. 11, исключение неприменимых направлений по п. 13.
- Отчёт по составу п. 35 Методики: значения a, Dij и Pзн, уровни направлений, профиль, недостатки и рекомендации.

Ссылки сразу на нужный режим:

- КЗИ: https://gleb-dvornikov.github.io/kzi-calculator/#kzi
- УЗИ: https://gleb-dvornikov.github.io/kzi-calculator/#uzi

## Устройство

Один файл `index.html` без сборки и серверной части. Ответы хранятся в localStorage браузера пользователя и никуда не передаются. Шрифт Montserrat подключается с Google Fonts.

В панели результата под кнопками есть предложение помощи УЦСБ, его текст зависит от результата. Ссылка «Получить план повышения» открывает в почтовой программе пользователя письмо на cybersec@ussc.ru со сводкой расчёта, отправляет его сам пользователь.

## Как обновить

Заменить `index.html` в репозитории. GitHub Pages обновляет сайт за 1-2 минуты.

## Перенос на домен УЦСБ

`index.html` размещается на любом веб-сервере как статическая страница, например на поддомене kzi.ussc.ru. Достаточно nginx с TLS-сертификатом.
