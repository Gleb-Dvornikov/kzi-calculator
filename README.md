# Калькулятор показателя защищённости Кзи

Расчёт Кзи по Методике оценки показателя состояния технической защиты информации (утв. ФСТЭК России 11.11.2025) и Требованиям, утверждённым приказом ФСТЭК России от 11.04.2025 № 117. Интерфейс в стиле CheckU (УЦСБ).

## Что умеет

- 16 частных показателей в четырёх группах с весами Методики
- точный расчёт Кзи и уровня защищённости без промежуточного округления
- отметка «Не применимо» для k13, k22, k31, k34 и k36, где Методика присваивает максимальное значение
- приоритизация несоответствий по приросту Кзи
- отчёт во ФСТЭК России в формате Word с приложением расчёта и текущий внутренний отчёт
- заявка на экспресс-повышение уровня защищённости

## Устройство

Один файл `index.html` без сборки и серверной части. Ответы хранятся в localStorage браузера пользователя и никуда не передаются. Шрифт Montserrat подключается с Google Fonts.

## Как обновить

Заменить `index.html` в репозитории. GitHub Pages обновляет сайт за 1-2 минуты.

## Перенос на домен УЦСБ

`index.html` размещается на любом веб-сервере как статическая страница, например на поддомене kzi.ussc.ru. Достаточно nginx с TLS-сертификатом.
