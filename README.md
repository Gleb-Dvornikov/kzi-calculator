# Калькулятор показателя защищённости Кзи

Самопроверка по Методике оценки показателя состояния технической защиты информации (утв. ФСТЭК России 11.11.2025) и Требованиям, утверждённым приказом ФСТЭК России от 11.04.2025 № 117. Интерфейс в стиле CheckU (УЦСБ).

## Как работает

- одна страница: справка, реквизиты для отчёта, 16 показателей в четырёх группах, полезная информация
- справа панель с текущим Кзи, уровнем защищённости и баллами групп
- показатель засчитывается, когда отмечены все его критерии
- кнопки «Сброс», «Текущий отчёт» и «Сформировать отчёт», отчёты выгружаются в Word

## Устройство

Один файл `index.html` без сборки и серверной части. Ответы хранятся в localStorage браузера пользователя и никуда не передаются. Шрифт Montserrat подключается с Google Fonts.

## Как обновить

Заменить `index.html` в репозитории. GitHub Pages обновляет сайт за 1-2 минуты.

## Перенос на домен УЦСБ

`index.html` размещается на любом веб-сервере как статическая страница, например на поддомене kzi.ussc.ru. Достаточно nginx с TLS-сертификатом.
